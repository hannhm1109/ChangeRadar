# ChangeRadar v0.1.0

ChangeRadar inspects Git changes and highlights deployment-impacting modifications before production: environment variables, migrations, API routes, dependencies, and scheduled jobs.

## Included

- Five deterministic MVP detectors with suggested deployment checks.
- Working-tree, single-ref, two-dot, and three-dot comparisons.
- Text reports and versioned JSON suitable for CI artifacts.
- Exit codes: `0` = no HIGH findings, `1` = HIGH findings, `2` = tool error.
- Privacy exclusions, merge-conflict checks, and explicit analysis/write errors.
- A runnable demo and GitHub Actions usage example.

## Try It

Requires Node.js 22.12 or newer, npm, and Git.

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/hannhm1109/ChangeRadar.git
cd ChangeRadar
npm ci --ignore-scripts
npm run build
npm run demo
```

The demo deliberately exits `1`: its fixture includes a HIGH-severity migration. A shallow checkout is sufficient for building/running this demo, which creates its own history. Fetch full history when analyzing this checkout's earlier commits.

See the [README](https://github.com/hannhm1109/ChangeRadar/blob/v0.1.0/README.md) for running the compiled tool against another Git repository, package installation, detector limitations, and CI guidance.
