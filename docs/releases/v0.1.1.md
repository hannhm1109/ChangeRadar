# ChangeRadar v0.1.1

Initial licensed public release of ChangeRadar, a CLI that highlights deployment-impacting Git changes.

- Detects new environment variables, database migrations, Next.js API routes, dependencies, and cron/deployment configuration changes.
- Supports working-tree analysis and committed two-dot/three-dot comparisons.
- Produces text or versioned JSON reports with deployment checks.
- Uses CI-friendly exit codes: `0` = no HIGH findings, `1` = HIGH findings, `2` = tool error.
- Includes 357 automated tests, a runnable demo, and package-install smoke checks.
- Licensed under MIT; detector behavior and JSON schema are unchanged from the `v0.1.0` candidate.

## Installation

Requires Node.js 22.12 or newer, npm, and Git.

Download the attached `changeradar-0.1.1.tgz`, verify its SHA-256 checksum, then install:

```bash
npm install --global --ignore-scripts ./changeradar-0.1.1.tgz
cd /path/to/your-application
changeradar analyze main...HEAD
```

The package contains compiled code; npm fetches its runtime dependencies. GitHub package installation does not depend on npm registry publication.

Alternatively, build from the tagged source:

```bash
git clone --branch v0.1.1 --depth 1 https://github.com/hannhm1109/ChangeRadar.git
cd ChangeRadar
npm ci --ignore-scripts
npm run build
npm run demo
```

The demo intentionally exits `1` because its fixture includes a HIGH migration finding. Fetch the required history before analyzing a shallow checkout's older commits.

See the [README](https://github.com/hannhm1109/ChangeRadar/blob/v0.1.1/README.md) for detector limitations and CI usage. npm publication is a separate distribution step; verify registry availability before using `npx changeradar`.
